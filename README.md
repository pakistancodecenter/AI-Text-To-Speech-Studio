# AI Text To Speech Studio

Professional AI Text To Speech Application built with Python.

## Features

- Urdu & English AI Voices
- Voice Cloning
- Subtitle Export
- MP3/WAV Support
- Emotion Voices
- Batch Conversion
- Modern GUI

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Requirements

- Python 3.10+
- FFmpeg Installed
